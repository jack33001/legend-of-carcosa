# Updating the site

cd into the quartz directory of the vault

```
cd ~/Documents/Obsidian Vaults/The Legend of Carcosa/quartz
```

run npx quartz sync

```
npx quartz sync
```

# Making a local build

```
npx quartz build --serve
```

Build will be hosted on port 8080 of localhost
# Themes

To change the theme:
```
npm run theme <theme-name>
```

To check for updates:
```
npm run check
```

To update:
```
npm run update
```
