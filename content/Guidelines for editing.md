**Tips for using Obsidian**
Putting something in double brackets (like this \[\[word]]), it becomes a tag. Tags link between pages, and are the heart of this system. If you click a tag, it'll bring you to the corresponding note; if the note doesn't exist yet, it'll create that note. This lets the whole system of notes evolve organically. 

# 1. When you make a new note, follow the prompts
When a new note is created, this vault is configured to prompt you for the note type, and will automatically create an appropriate header and place the note in the proper folder. If none of the labels match up with your note type, just type anything, and a blank header will appear. *Don't exit the prompt, or a blank note will be created without being placed in the proper folder.*

# 2. When you're done editing, push the repository immediately
If you wait too long between editing and syncing the notebook, somebody may edit it at the same time, potentially creating merge conflicts. This isn't world ending, but can just be a pain sometimes.

# 3. Don't create session notes
This will very likely cause a merge conflict, as I'll be creating one each session. Feel free to edit existing session notes, of course. 

# 4. Ask me before installing plugins
Not all Obsidian plugins are compatible with the website generation service this uses (most custom formatting plugins, for example, that deviate from standardized markdown syntax), so let me know if there's a plugin you want to use and I can test it first.
